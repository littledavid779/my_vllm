# 严格因果校准：固定选点，改变 mask

本轮检验长后缀质量差距中有多少来自查询原位置与 mask 不匹配。它属于 baseline 执行校准，不是新的 token 选择算法。

固定 LMCache 0.3.13 / vLLM 0.11 / Qwen3-8B，检查层 1、K 平方差 top-k、15% 预算、等长编辑、同一会话缓存来源和 B′ 预计算流程。新 B′ 准备的完整时间继续计入客户端 TTFT。仅在独立工程/实验分支修改专用 venv，可恢复。

## 精确 mask

对每个选择查询保留其原始位置 p，允许读取的 key 位置恰为 j <= p。使用 FlashInfer 0.3.1 公开 single-prefill custom-mask 接口，按行 little-endian 打包；每个请求在检查层构建/打包一次，其后各层复用。不按 32 个查询近似，不以压缩后的行号替代原位置，不改选点或预算。RoPE 仍由上游按原位置执行。

先验证 GPU primitive：BF16 / 32 Q heads / 8 KV heads / head size 128；非连续查询、位置 0、31/32 边界、非 8 整除长度。与独立 float32 attention 和完整 causal attention 的对应行比较；另将所有未来 K/V 扰动 100，过去 Q 的输出必须保持不变。原始索引不得被改写，打包/解包的 mask 必须逐位一致。

## 小对照

先使用已固定的 12 来源、24 条链、每链 3 次编辑；所有样本保留，不按完整重算正确率过滤。重新测量同一 FlashInfer 后端的完整重算、精确前缀、严格 mask 15%、严格 mask 100%。100% 是执行一致性控制，不作为优化方案；若它仍产生明显质量差距，先检查集成/KV 写入/分隔符，再解释 15% 的误差。
本机负载已经变化，旧轮次的 TTFT 不用于直接判断本轮延迟约束。质量可以逐请求对照旧结果，但必须标明后端配置和总体不同。

### 小对照触发的写回校验

首次严格 mask 小对照中，100% 档仍有 3 个 full 正确、该档错误的事件。代码与独立 CPU 回归用例确认：检查层之前 `process_qkv` 返回新算 K/V 用于当前 attention，却未更新 GPU connector 最后导出的旧缓冲，尤其分隔符缺口保留为 0。增加独立开关，将这些已全量计算的层的 K/V 复制回传输缓冲；检查层打分与选点后分支不变。重新核验同一 15% / 100% 档，旧结果保留，不将它们混入修改后结果。
扩展中的严格/block-mask 两组应使用同一写回设置，避免把集成差异当成 mask 差异。
写回修正后，100% 档剩下 1 个新增错误，与原生精确前缀的同一事件一致；不宣称与 full 位级一致。

## 扩展规则

GPU primitive 和小对照可正常完成后，使用同一原始来源池中小对照以外的 96 来源，仅取 early8k 长后缀布局；不依据模型输出选题或调参。测 full、prefix、严格 mask 15%、上一轮激活的 32-query block mask 15%。重新测量，保留完整源码/配置/输入哈希。
至少两次服务重启的重复测量，缓存从头建立，避免重复输入被 APC 完全命中；轮次之间交换严格/block-mask 的运行顺序。按来源聚类统计质量差值，重复测量不增加独立样本数。质量结果不只报告 full 正确的子集；同时单列缓存新增错误、反向答对、输出不一致和编辑轮次。
由于严格 15% 在小对照耗时约 306 ms，扩展前追加纯耗时预算校准：重新测相同写回设置的 block 15%，以及 strict 5% / 10%，并保留刚测的 strict 15%。只用 early8k 的平均 TTFT 选最接近 block 15% 的比例；若网格未落入 ±5%，允许一次基于耗时线性插值的整数比例测量。此选择不读取正确率或模型答案。比例在接触扩展结果前写入 `calibration.json`，扩展时不再调参。
实际校准选定 strict 10% 对照 block 15%，分别为 233.66 / 236.00 ms；扩展沿用此冻结比例。它替代上文原定扩展的 strict 15%，同预算比较保留在小对照中。
两次重复中新测严格/block 两组；native full/prefix 在扩展第一轮重测一次，后续通过输入/配置/完整性校验复用，不能把复用记录算成新的延迟测量。
长后缀布局为前移事实加重复背景的衍生压力测试，不是官方 BABILong 排行榜。尚不声称覆盖真实线上混合负载、吞吐或连续近似缓存写回后的误差累积。

若本轮严格因果能稳定改善质量，再讨论 token 选择；若代价明显超过约 250 ms，则作为正确性参考，不能声称达成“TTFT 基本不变”。接口修正和 mask 校准不作为论文创新。
