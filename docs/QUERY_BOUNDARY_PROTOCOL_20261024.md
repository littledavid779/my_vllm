# 问题缓存边界与输入表达的机制筛查

本轮保留已有 17.36 个百分点的结果，验证它对问题缓存方式和答案表达的依赖。该实验为探索性机制分析，不预设产生新的选择算法，也不预设已有方法会获得相同数值。

## 来源与输入

本地未评测且满足单事实改写条件的 QA9 仅余 92、94、98、99 四个来源，保留给后续确认性实验。本轮固定从 `query_fair_v1` 的来源按 ID 顺序选择 QA9 16 个、QA2 8 个、QA3 8 个，均为已经评测的来源；不按模型输出挑选。

每个来源保留三个真实等长编辑，使用原问法、语义等价改写、答案标签映射三个版本，形成 96 个会话和 288 个编辑事件。QA9 的标签映射为 yes/no 到 true/false；QA2/QA3 使用固定一一对应的地点标签。事实和 oracle 使用原问题解释，输出标准答案按映射转换。所有变体均使用单独的新记录 ID，防止会话之间共享旧 KV。

本轮仅使用事实提前、后接 7600 背景 token 的 early8k 压力布局。输入变体不要求彼此等长，但每条编辑链等长，所有方法接收完全相同的 token-ID 输入。结果不是官方 BABILong 分数，不能视为自然负载或未见来源上的确认性结果。

## 对照与实际执行

- full：完整重算。
- prefix：标准精确前缀缓存。
- topk：缓存问题与上下文，使用全局 K 差异 top-k。
- query：缓存问题与上下文，预算内强制重算完整问题和回答起始模板，其余位置按 K 差异选择。
- fresh：不存储、不检索问题及模板的旧 KV；仅混合上下文，然后由 vLLM 正常前向计算完整问题与模板。

三个近似组统一在 token 数据库中隐式拆分 C 与问题，不插入额外分隔符，不改变 token、位置编码或因果关系。缓存问题的 key 使用完整 C 片段作上下文区分，防止相同问题跨会话命中。fresh 截断后上下文的 key 与播种时一致。

适配器记录实际注意力元数据中的 `num_actual_tokens`。逐请求审计要求 fresh 的缓存命中恰好止于问题开始，正常前向的 token 数恰好覆盖问题及模板，混合计算不能包括这部分；缓存两组完整命中，正常前向为最后一个 token。

名义预算为输入总长的 10%。query 的强制位置从总预算扣除；fresh 将问题及模板的原生计算位置从预算扣除后再选择上下文位置。缓存组还有一次用于生成首 token 的普通最后 token 计算，fresh 则没有该额外重复；早层探测范围不同。因此不宣称完全等 FLOPs，报告预算口径和实际计算位置，并使用真实端到端 TTFT。

所有近似组共用严格原位置因果 mask 和早层 KV 写回修正。已有实验分支、原始结果和上游源码保持保留，新补丁只作用于独立虚拟环境，结束或异常时恢复。

## 验证与执行顺序

先通过 CPU 单元测试，检查分段位置、跨会话 key 区分、上下文截断检索一致性、预算和正常问题前向的审计拒绝条件。GPU 阶段先用同一 QA9 来源的三个变体做 100% 预算 smoke，要求完整任务正确性与 full 一致、缓存命中和实际前向位置审计通过，之后才测 10% 预算。

正式测量两次，近似组顺序 topk/query/fresh 及其反序。每轮首次运行时重新测 full 和 prefix，在同一轮后续阶段仅复用其记录，分析只计一次。共 1728 次近似编辑测量和 1152 次原生 full/prefix 编辑测量；额外 smoke、缓存播种、B′ 准备和预热单列，不计入独立来源。

GPU 0/1 每 30 秒检查，连续三次无进程、显存不超过 100 MiB、利用率不超过 5% 后选卡，全程固定同一张卡，阶段之间继续检查；每次等待上限 24 小时。运行期检测外来 GPU 进程，冲突时停止并恢复，不终止其他人的任务。

## 报告与解释

记录任务正确率、完整重算正确而近似组错误及反向情况、平均/P95 端到端 TTFT、实际问题计算路径和选点数。TTFT 包括 B′ 准备、检索、搬运、选择、修复、正常问题计算、日志与调度；不含初次播种、分词和首 token 后解码。

按来源聚类，携带所有编辑、变体与重复，报告 query-topk、fresh-topk、query-fresh 的差异和置信区间。标签变体需同时查看 full 的变化，不能把指令遵循难度误归于缓存。零差异不证明等效，探索性区间不作多重比较校正。

若 query 和 fresh 表现相近，说明必须认真核对输入分块和问题计算口径，不能把补算问题本身宣称为新增机制；若原问法有效而改写/标签变体失效，收窄适用结论；若现象跨表达稳定，再扩展模型和自然布局。当前不宣称 EPIC 完整系统复现、长期近似缓存误差累积或吞吐收益。
