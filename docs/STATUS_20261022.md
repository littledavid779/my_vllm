CacheBlend 先单独处理本次新 B′ 以满足块已缓存的要求，其准备请求全耗时已经计入上述客户端 TTFT；主请求 TTFT 另存。该版本直接遇到未缓存的 B′ 会停止查找，因此未修改 lookup 就无法把“新块未准备”的请求直接用于后缀融合对比。
启用了官方 `save_unfull_chunk`，使末尾 C 完整保存。尚未尝试将适配流程合并为一个请求；不能将两个请求的开销当成论文实现本身的固有下界。
